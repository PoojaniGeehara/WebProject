# TechXplore 🛒⚡

**TechXplore** is a responsive web front-end for an electronic equipment and tech store. It features a curated product catalog, user/admin authentication sections, customer testimonials, and quick contact details.

---

## 🌟 Features

- **Navigation Bar:** Easy layout with quick links to sections, search bar, and cart icon.
- **Hero & About Sections:** Introduces the store's mission and offerings.
- **Product Gallery:** Grid display of featured tech products with prices, images, and quick action buttons (*Buy Now*, *Add to Cart*).
- **Authentication Forms:**
  - Standard User Sign In
  - Admin Sign In
  - Account Creation Form
- **Customer Feedback:** Section showcasing customer reviews and star ratings.
- **Footer:** Social links, quick navigation, support links, and contact information.
